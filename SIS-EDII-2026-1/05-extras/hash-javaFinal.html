O que é uma tabela hash?
01Você já conhece array. Para buscar um valor num array, você percorre posição por posição até achar.
02Uma tabela hash é uma estrutura que não procura. Ela calcula em qual posição o dado está.
03Para isso, ela usa uma função hash. Essa função recebe a chave do dado e devolve um número. Esse número é a posição no array.
04A chave pode ser qualquer coisa: um nome, um CPF, um código de produto, um número de matrícula. O que define a chave é o problema que você está resolvendo.
05Neste exemplo, vamos construir uma agenda de contatos. A chave será o nome da pessoa.
Array comum
Para achar "Carlos", compara nome por nome do índice 0 até encontrar. Com 1000 contatos, pode comparar até 1000 vezes.
O(n)
Tabela hash
Calcula a posição de "Carlos" na hora. Vai direto lá. Não importa se tem 10 ou 10 mil contatos.
O(1)
Para fixar
Hash não procura. Hash calcula onde o dado está.

A função hash
01A função hash precisa transformar uma chave em um número inteiro. Esse número vai ser o índice do array.
02Se a chave for um número inteiro, é simples: o próprio número pode virar o índice.
03Se a chave for uma String, precisamos converter. A estratégia mais simples é somar os valores numéricos de cada caractere.
04Todo caractere já tem um número definido pelo padrão ASCII. A letra A vale 65, B vale 66, a vale 97. O Java acessa esse valor automaticamente quando você usa um char numa operação matemática.

Existem várias funções hash
01A soma de ASCII é apenas uma forma de fazer hash. Não é a única, nem a melhor.
02Existem muitas funções hash diferentes. Cada uma distribui os dados de um jeito. Umas geram menos colisões que outras.

TabelaHash.java novo
public class TabelaHash {
    private static final int TAMANHO = 7;
    private Contato[] tabela = new Contato[TAMANHO];

    private int hash(String chave) {
        int soma = 0;
        for (char c : chave.toCharArray()) {
            soma += c;          // Java usa o valor ASCII do char
        }
        return soma % TAMANHO;  // garante que o indice cabe no array
    }
}

Etapa 5 de 9
O problema: colisão
01O array tem 7 posições. Os nomes possíveis são infinitos. Cedo ou tarde, dois nomes diferentes vão gerar o mesmo índice.
02Isso se chama colisão. Não é um bug nem um descuido. É uma consequência matemática inevitável.
03Exemplo concreto: "Ana" e "Naa" têm as mesmas letras em ordem diferente. A soma do ASCII é idêntica. Os dois geram o índice 6.
04Com a implementação atual, se você inserir "Naa" depois de "Ana", o dado de "Ana" é apagado. A posição 6 fica só com "Naa".
Naa sobrescrevendo Ana na posição 6
"Ana"hash()6 e também "Naa"hash()6
Para fixar
Colisão é inevitável. O que diferencia uma boa implementação é como ela trata esse problema.

Etapa 6 de 9
Resolvendo a colisão
01O problema é simples: cada posição do array comporta apenas um contato. Quando dois querem a mesma posição, um apaga o outro.
02A solução é fazer cada posição comportar mais de um contato.
03Para isso, em vez de guardar um Contato em cada posição, vamos guardar uma lista de contatos.
04O Java já tem uma lista pronta que serve bem: a ArrayList. Ela permite adicionar quantos itens quisermos, sem definir tamanho antes.
05A tabela deixa de ser um array de contatos e passa a ser uma lista de listas: ArrayList<ArrayList<Contato>>. A tabela é uma lista. Cada posição dela guarda outra lista. Cada uma dessas guarda os contatos.
Agora Ana e Naa convivem na lista da posição 6
Para fixar
Essa técnica tem nome: encadeamento, ou chaining em inglês. Cada posição da tabela encadeia uma lista de contatos que colidiram.

Etapa 7 de 9
Atualizando a classe
01Agora vamos reescrever TabelaHash usando uma ArrayList em cada posição.
02No construtor, criamos a lista principal e adicionamos uma lista vazia para cada uma das 7 posições. Sem isso, não haveria onde guardar os contatos.
03No inserir, antes fazíamos tabela[indice] = contato. Agora fazemos tabela.get(indice).add(contato). Pegamos a lista daquela posição e adicionamos o contato nela.
04Repare na diferença: como agora é uma ArrayList e não mais um array, acessamos cada posição com .get(indice) em vez de colchetes [indice].
TabelaHash.java atualizado
import java.util.ArrayList;

public class TabelaHash {
    private static final int TAMANHO = 7;
    private ArrayList<ArrayList<Contato>> tabela;

    public TabelaHash() {
        tabela = new ArrayList<ArrayList<Contato>>();
        for (int i = 0; i < TAMANHO; i++) {
            tabela.add(new ArrayList<Contato>()); // uma lista vazia por posicao
        }
    }

    private int hash(String chave) {
        int soma = 0;
        for (char c : chave.toCharArray()) soma += c;
        return soma % TAMANHO;
    }

    public void inserir(Contato contato) {
        int indice = hash(contato.nome);
        tabela.get(indice).add(contato); // adiciona na lista, nao substitui
        System.out.println("Guardado em [" + indice + "]: " + contato);
    }
}
Para fixar
A mudança foi pequena no código, mas grande no comportamento. Antes: colisão apagava. Agora: colisão acumula na lista.

Buscando um contato
01Para buscar, usamos a mesma hash() que usamos para inserir. Passamos o nome, ela devolve o índice.
02Vamos direto para aquela posição no array. Sem percorrer tudo.
03Aquela posição tem uma lista. Percorremos essa lista comparando o nome de cada contato com o nome buscado.
04Na maioria dos casos, a lista tem apenas um contato. A busca é praticamente direta.
Buscando Carlos: calcula o índice e vai direto

public Contato buscar(String nome) {
    int indice = hash(nome);   // mesmo calculo do inserir

    for (Contato c : tabela.get(indice)) {
        if (c.nome.equals(nome)) {
            return c;          // achou
        }
    }
    return null;               // nao encontrado
}

public void exibirBusca(String nome) {
    Contato resultado = buscar(nome);
    if (resultado != null) {
        System.out.println("Encontrado: " + resultado);
    } else {
        System.out.println(nome + " nao encontrado.");
    }
}
Para fixar
A função hash que guardou o contato é a mesma que encontra. Esse é o segredo da tabela hash.

TabelaHash.java
import java.util.ArrayList;

public class TabelaHash {
    private static final int TAMANHO = 7;
    private ArrayList<ArrayList<Contato>> tabela;

    public TabelaHash() {
        tabela = new ArrayList<ArrayList<Contato>>();
        for (int i = 0; i < TAMANHO; i++) {
            tabela.add(new ArrayList<Contato>());
        }
    }

    private int hash(String chave) {
        int soma = 0;
        for (char c : chave.toCharArray()) soma += c;
        return soma % TAMANHO;
    }

    public void inserir(Contato contato) {
        int indice = hash(contato.nome);
        tabela.get(indice).add(contato);
        System.out.println("Guardado em [" + indice + "]: " + contato);
    }

    public Contato buscar(String nome) {
        int indice = hash(nome);
        for (Contato c : tabela.get(indice)) {
            if (c.nome.equals(nome)) return c;
        }
        return null;
    }

    public void exibirBusca(String nome) {
        Contato resultado = buscar(nome);
        if (resultado != null)
            System.out.println("Encontrado: " + resultado);
        else
            System.out.println(nome + " nao encontrado.");
    }

    public void exibir() {
        System.out.println("=== TABELA HASH ===");
        for (int i = 0; i < TAMANHO; i++) {
            System.out.print("[" + i + "] ");
            if (tabela.get(i).isEmpty()) {
                System.out.println("vazio");
            } else {
                for (Contato c : tabela.get(i)) System.out.print(c + "  ");
                System.out.println();
            }
        }
        System.out.println("===================");
    }
}

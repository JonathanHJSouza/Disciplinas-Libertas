Etapa 1 de 6

O problema a ser resolvido

Antes de escrever qualquer código, precisamos entender o que queremos modelar. Todo programa começa com um problema real.

Enunciado

Uma empresa de logística precisa mapear a malha rodoviária entre cidades de Minas Gerais. Cada cidade é um ponto de distribuição. Cada estrada conecta duas cidades e tem uma distância em quilômetros.

O sistema deve:

  • Armazenar a malha nas duas formas clássicas: matriz de adjacências e lista de adjacências.
  • Exibir as duas representações para o mesmo conjunto de dados.
  • Informar o grau de cada cidade, ou seja, quantas estradas partem dela diretamente.

Os dados de entrada estão fixos no programa. São cinco cidades e cinco estradas:

EstradaDistância
Uberlândia → Uberaba120 km
Uberlândia → Ituiutaba130 km
Uberaba → Araxá80 km
Araxá → Patos de Minas95 km
Patos de Minas → Ituiutaba200 km

Duas observações importantes que vão guiar o projeto do código:

As estradas não têm sentido obrigatório. Se existe estrada de A para B, existe também de B para A. O grafo é não-direcionado. Na matriz, isso vai gerar uma estrutura simétrica.

As distâncias são relevantes. O grafo é ponderado: cada aresta carrega um valor numérico associado.

Representação visual do grafo: 5 vértices, 5 arestas, ponderado e não-direcionado.

Conceitos fundamentais que o código vai expressar

Antes de escrever as classes, vale mapear o que cada conceito do problema se tornará no código.

◉

Vértice

Cada cidade. No código, representado por um índice inteiro (0 a 4) e um nome em um array de Strings.

—

Aresta

Cada estrada. Tem um destino (índice da cidade) e um peso (distância em km). Vira uma classe Java.

↔

Não-direcionado

Ao inserir uma estrada de A para B, o código também insere de B para A. Sempre nos dois sentidos.

#

Ponderado

Cada aresta carrega um valor numérico. Na matriz, o valor da célula é o peso, não apenas 0 ou 1.

▦

Matriz de adjacências

Grade n×n onde a célula [i][j] guarda a distância entre as cidades i e j. Zero significa sem conexão.

≡

Lista de adjacências

Cada cidade tem uma lista com suas vizinhas diretas. Mais eficiente em memória para grafos pouco densos.

O grafo deste problema tem n = 5 vértices e m = 5 arestas. A matriz vai ocupar sempre n² = 25 posições. A lista vai ocupar n + 2m = 15 posições (cada aresta aparece duas vezes por ser não-direcionada). Para grafos maiores e pouco densos, a lista é mais econômica.

Observação sobre simetria. Em um grafo não-direcionado, a matriz de adjacências é sempre simétrica: o valor em [i][j] é igual ao valor em [j][i]. Isso vai aparecer claramente na saída do programa.

Primeira parte do código: a classe Aresta

O programa tem duas classes. Começamos pela menor: Aresta. Ela representa uma única conexão entre duas cidades.

Uma aresta precisa guardar duas informações: para qual cidade ela aponta e qual é a distância. Nada mais.

RedeRodoviaria.java 
import java.util.ArrayList;

public class RedeRodoviaria {

        // Representa uma única estrada: para onde vai e qual é a distância
        static class Aresta {
        int destino;
        int distanciaKm;

                Aresta(int destino, int distanciaKm) {
            this.destino = destino;
            this.distanciaKm = distanciaKm;
        }
    }

        // ... a classe Grafo vem a seguir

}
Por que uma classe separada? Poderíamos guardar só o índice do destino e usar a matriz para os pesos. Mas criar a classe Aresta deixa o código mais legível e facilita adicionar novos atributos depois, como tempo de percurso ou capacidade da via.

Repare que a classe é declarada como static porque está dentro de outra classe (RedeRodoviaria). Isso significa que ela não depende de uma instância da classe externa para existir.

O construtor recebe os dois valores e os atribui diretamente. Não há lógica adicional aqui: a aresta apenas armazena dados.

Segunda parte: a classe Grafo

A classe Grafo guarda as duas representações ao mesmo tempo e oferece métodos para inserir estradas. Veja sua estrutura:

RedeRodoviaria.java 
    static class Grafo {
        int n;
        String[] nomes;

                // Representação 1: matriz n×n com as distâncias
                int[][] matriz;

                // Representação 2: para cada vértice, uma lista de vizinhos
                ArrayList<ArrayList<Aresta>> lista;

                Grafo(String[] nomes) {
            this.n = nomes.length;
            this.nomes = nomes;

                        // Aloca a matriz n×n (Java já a preenche com zeros)
            matriz = new int[n][n];

                        // Aloca a lista: uma ArrayList para cada vértice
            lista = new ArrayList<>();
            for (int i = 0; i < n; i++) {
                lista.add(new ArrayList<>());
            }
        }

                // ... métodos a seguir
    }
Por que ArrayList<ArrayList<Aresta>>? É a forma de criar uma lista de listas em Java sem a necessidade de definir um tamanho máximo fixo. Cada posição da lista externa corresponde a um vértice e contém outra lista com todas as arestas que partem dele.

Agora o método que insere uma estrada. Ele atualiza as duas representações ao mesmo tempo:

RedeRodoviaria.java 
        void adicionarEstrada(int a, int b, int km) {

                        // Matriz: dois lados, porque o grafo é não-direcionado
            matriz[a][b] = km;
            matriz[b][a] = km;

                        // Lista: aresta inserida nas duas direções também
            lista.get(a).add(new Aresta(b, km));
            lista.get(b).add(new Aresta(a, km));
        }

A linha matriz[a][b] = km registra a distância da cidade a para a cidade b. A linha seguinte, matriz[b][a] = km, faz o mesmo no sentido contrário. É isso que torna a matriz simétrica. O mesmo princípio se aplica à lista.

Métodos de exibição e o main

Com as estruturas prontas, os métodos de exibição percorrem e imprimem o que foi armazenado. Cada um ilustra uma propriedade diferente das representações.

Imprimindo a matriz:

RedeRodoviaria.java 
        void imprimirMatriz() {
            System.out.println("=== Matriz de adjacências (km) ===");
            System.out.printf("%20s", "");
            for (int i = 0; i < n; i++)
                System.out.printf("%20s", nomes[i]);
            System.out.println();

            for (int i = 0; i < n; i++) {
                System.out.printf("%20s", nomes[i]);
                for (int j = 0; j < n; j++)
                    System.out.printf("%20d", matriz[i][j]);
                System.out.println();
            }
        }

O resultado visual da matriz para os nossos dados. Note a diagonal de zeros e a simetria:

Uberlândia Uberaba Araxá Patos Ituiutaba
Uberlândia 0 120 0 0 130
Uberaba 120 0 80 0 0
Araxá 0 80 0 95 0
Patos 0 0 95 0 200
Ituiutaba 130 0 0 200 0

Imprimindo a lista e o grau:

RedeRodoviaria.java 
        void imprimirLista() {
            System.out.println("\n=== Lista de adjacências ===");
            for (int i = 0; i < n; i++) {
                System.out.print(nomes[i] + ":");
                for (Aresta a : lista.get(i))
                    System.out.print(" -> " + nomes[a.destino] + " (" + a.distanciaKm + " km)");
                System.out.println();
            }
        }

        void mostrarGrau() {
            System.out.println("\n=== Grau de cada vértice ===");
            for (int i = 0; i < n; i++)
                System.out.println(nomes[i] + ": grau " + lista.get(i).size());
        }
Grau via lista. O grau de um vértice é simplesmente o tamanho da sua lista de adjacências: lista.get(i).size(). Cada estrada inserida adicionou uma Aresta nessa lista, nos dois sentidos. Por isso todas as cidades têm grau 2 neste exemplo: o grafo foi construído como uma cadeia linear.

Por fim, o main cria o grafo, insere as estradas e chama os três métodos:

RedeRodoviaria.java 
    public static void main(String[] args) {
        String[] cidades = {"Uberlândia", "Uberaba", "Araxá", "Patos de Minas", "Ituiutaba"};

        Grafo g = new Grafo(cidades);

        g.adicionarEstrada(0, 1, 120);  // Uberlândia - Uberaba
        g.adicionarEstrada(0, 4, 130);  // Uberlândia - Ituiutaba
        g.adicionarEstrada(1, 2, 80);   // Uberaba - Araxá
        g.adicionarEstrada(2, 3, 95);   // Araxá - Patos de Minas
        g.adicionarEstrada(3, 4, 200);  // Patos de Minas - Ituiutaba

        g.imprimirMatriz();
        g.imprimirLista();
        g.mostrarGrau();
    }

Etapa 6 de 6

Código completo

Todas as partes reunidas em um único arquivo. Pronto para compilar e executar.

O que este programa demonstra

  • Modelagem de um grafo ponderado e não-direcionado
  • Representação por matriz de adjacências: custo de memória O(n²), simétrica, acesso direto a qualquer par de vértices
  • Representação por lista de adjacências: custo de memória O(n + m), mais eficiente para grafos pouco densos
  • Grau de um vértice obtido diretamente pelo tamanho da sua lista
  • As duas representações mantidas sincronizadas a cada inserção
RedeRodoviaria.java 
import java.util.ArrayList;

public class RedeRodoviaria {

        // Representa uma única estrada: para onde vai e qual é a distância
        static class Aresta {
        int destino;
        int distanciaKm;

                Aresta(int destino, int distanciaKm) {
            this.destino = destino;
            this.distanciaKm = distanciaKm;
        }
    }

        // Grafo ponderado não-direcionado com duas representações simultâneas
        static class Grafo {
        int n;
        String[] nomes;
        int[][] matriz;
        ArrayList<ArrayList<Aresta>> lista;

                Grafo(String[] nomes) {
            this.n = nomes.length;
            this.nomes = nomes;
            matriz = new int[n][n];
            lista = new ArrayList<>();
            for (int i = 0; i < n; i++)
                lista.add(new ArrayList<>());
        }

                // Insere a estrada nos dois sentidos (grafo não-direcionado)
                void adicionarEstrada(int a, int b, int km) {
            matriz[a][b] = km;
            matriz[b][a] = km;
            lista.get(a).add(new Aresta(b, km));
            lista.get(b).add(new Aresta(a, km));
        }

                void imprimirMatriz() {
            System.out.println("=== Matriz de adjacências (km) ===");
            System.out.printf("%20s", "");
            for (int i = 0; i < n; i++)
                System.out.printf("%20s", nomes[i]);
            System.out.println();
            for (int i = 0; i < n; i++) {
                System.out.printf("%20s", nomes[i]);
                for (int j = 0; j < n; j++)
                    System.out.printf("%20d", matriz[i][j]);
                System.out.println();
            }
        }

                void imprimirLista() {
            System.out.println("\n=== Lista de adjacências ===");
            for (int i = 0; i < n; i++) {
                System.out.print(nomes[i] + ":");
                for (Aresta a : lista.get(i))
                    System.out.print(" -> " + nomes[a.destino] + " (" + a.distanciaKm + " km)");
                System.out.println();
            }
        }

                void mostrarGrau() {
            System.out.println("\n=== Grau de cada vértice ===");
            for (int i = 0; i < n; i++)
                System.out.println(nomes[i] + ": grau " + lista.get(i).size());
        }
    }

        public static void main(String[] args) {
        String[] cidades = {
            "Uberlândia", "Uberaba", "Araxá", "Patos de Minas", "Ituiutaba"
        };

        Grafo g = new Grafo(cidades);

        g.adicionarEstrada(0, 1, 120);
        g.adicionarEstrada(0, 4, 130);
        g.adicionarEstrada(1, 2, 80);
        g.adicionarEstrada(2, 3, 95);
        g.adicionarEstrada(3, 4, 200);

        g.imprimirMatriz();
        g.imprimirLista();
        g.mostrarGrau();
    }
}
